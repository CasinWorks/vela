# Vela Concierge

Luxury ground transportation sibling site for the **Vela Private** studio concept.

## Current fleet (concept)

- **Mercedes-Benz GLE** — max 6 passengers
- **Range Rover** — max 4 passengers

## Local development

```bash
npm install
npm run dev
```

Runs at [http://localhost:3002](http://localhost:3002).

Booking email via `/api/booking-notify` is optional — leave Resend unset for a UI-only demo.
