# Vela Aviation

Private aviation sibling site for the **Vela Private** ecosystem.

## Local development

```bash
npm install
npm run dev
```

Runs at [http://localhost:3001](http://localhost:3001).

Linked from the parent portal at `http://localhost:3000`. Override URLs with `VITE_PARENT_URL`, `VITE_AVIATION_URL`, and `VITE_CONCIERGE_URL`.
